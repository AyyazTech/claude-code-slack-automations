# PR Reviewer — Slack Prompt

Replace `OWNER/REPO` and the PR number with your own:

```
@Claude review github.com/OWNER/REPO/pull/N — focus on bugs and missing tests
```

## Variations

**Security-focused review:**
```
@Claude review github.com/OWNER/REPO/pull/N — focus on security issues, input validation, and authentication flaws
```

**Performance-focused review:**
```
@Claude review github.com/OWNER/REPO/pull/N — focus on performance: N+1 queries, missing indexes, unnecessary loops
```

**Post inline GitHub comments:**
```
@Claude review github.com/OWNER/REPO/pull/N — read the diff, identify issues, and post inline review comments directly on GitHub for each concrete bug
```

**Style-focused review:**
```
@Claude review github.com/OWNER/REPO/pull/N — focus on code style, readability, and naming. Match the existing patterns in the repo.
```
