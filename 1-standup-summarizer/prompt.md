# Standup Summarizer — Slack Prompt

Copy-paste this in your `#standup` channel:

```
@Claude summarize the last 24 hours of this channel into 3 bullets — what each person worked on, blockers, and shipped items
```

## Variations

**Specific person:**
```
@Claude summarize the last 24 hours of this channel — focus only on Alice and Bob's updates
```

**Specific time window:**
```
@Claude summarize the last 48 hours of this channel — group as: shipped, in progress, blockers
```

**Including action items:**
```
@Claude summarize the last 24 hours of this channel into 3 bullets PLUS list any unresolved action items mentioned
```
